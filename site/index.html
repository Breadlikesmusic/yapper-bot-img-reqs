Deepwoken Builder

A Yapper bot that reads deepwoken.co builder links.

Home Game data

What it does

Drop a builder link in any server the bot is in and it answers with the build's stats, talents and mantras.

Every stat is shown twice, once before the shrines ran and once after.

Try it

Paste a link, or reply to one with the command.

/build https://deepwoken.co/builder?id=RD42e4se

Replying to a link with just /build works too. Mentioning the bot does the same.

Add it to your server

Open Yapper, go to Server settings, then Bots and Your bots, and add DWB.

Search tips

Names are matched loosely, so silent hart finds Silentheart and needles eye finds Needle's Eye. You can also search by what something does, so burn finds the fire talents.

Not affiliated with Deepwoken or its developers. Game data comes from the public builder API and the Deepwoken wiki.
